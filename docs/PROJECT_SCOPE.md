# ExamSphere Project Scope

## Aim
To design and develop a secure, responsive and scalable web-based platform for conducting online quizzes and examinations, managing question banks, evaluating attempts and presenting performance analytics.

## Core Functional Requirements
1. User registration and authentication.
2. Role-based access control.
3. Student dashboard.
4. Teacher dashboard.
5. Administrator dashboard.
6. Question bank management.
7. Subject and topic management.
8. Examination creation and scheduling.
9. Configurable duration and marks.
10. Negative marking.
11. Randomized questions/options.
12. Timed examination interface.
13. Mark for review.
14. Automatic submission.
15. Automatic evaluation.
16. Result generation.
17. Performance analytics.
18. Attempt history.
19. Audit logs.
20. Notifications.

## Non-Functional Requirements
- Responsive UI
- Security
- Reliability
- Maintainability
- Usability
- Performance
- Scalability
- Data integrity
